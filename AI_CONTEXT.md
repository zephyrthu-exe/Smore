# Smore AI Context

## Project

Smore (Save More), a student-focused personal finance tracker and saving assistant.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- Bootstrap
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Functions

## Rules

- Do not use React, TypeScript, or another frontend framework.
- Use MMK for the school demo.
- Keep the interface beginner-friendly and polished.
- Do not expose Firebase server credentials or Gemini API keys in frontend files.
- Validate imported records before saving them.
- Smore performs all financial calculations deterministically.
- Gemini only interprets validated financial data and answers questions.
- Do not add banking connections, payments, investments, crypto, or multiple AI providers.
- Only one agent may modify a file or task at a time.

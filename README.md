# Smore (Save More)

Smore is a personal finance tracker built by UIT First Year 2nd Semester Students as a school project. It helps students manage finances with login, transactions, budgets, savings goals, and analytics.

## Current stack

- HTML, CSS, and Vanilla JavaScript
- Bootstrap
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Functions for protected Gemini API requests

## Scope

Smore supports login, transactions, budgets, savings goals, importing records, analytics, and Gemini-powered interpretation.

Financial calculations belong to Smore. Gemini interprets validated data and provides explanations; it does not own the numbers.

## Start locally

Open `src/index.html` with a local development server.

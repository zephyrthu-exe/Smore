# Smore Features

## Essential

- Register, login, and logout
- Personal dashboard
- Add, edit, and delete transactions
- Income and expense categories
- Transaction history
- Budget tracking
- Savings goals
- Basic analytics
- Import financial records with validation
- Gemini-powered interpretation
- Smore Assistant
- Recurring income and expense schedules
- 30-day commitment projection and safe-to-spend balance
- Optional previous-month budget rollover

## Secondary

- Search and filters
- Date filtering
- Monthly comparison
- Spending trends
- Budget warnings
- Export data
- Profile settings
